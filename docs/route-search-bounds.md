# 路线候选范围收紧

适用于工程师途中采购和多目标途经规划，不改变一般主界面查询的距离语义。

## 安全几何边界

设起终点为 A、B，单个途经点为 P，允许的总直线距离为 L。任何可行路线都必须满足：

```text
distance(A, P) + distance(P, B) <= L
```

可行区域是以 A、B 为焦点的旋转椭球。中点 M 的安全包围球半径为 `L / 2`；长半轴 `a=L/2`，短半轴 `b=sqrt(L²-|AB|²)/2`。星系查询还可使用其轴对齐包围盒，站点查询不假设支持相同坐标筛选字段。

采购中的 `L = (直达估算跳数 + 允许额外跳数) × 单跳航程`。这是必要条件，不等同于额外跳数规则；最终仍按各段独立向上取整的跳数核对，不能把“总距离可行”冒充“估算跳数可行”。

多目标规划中的 `L = |AB| + 最大额外路程`。每个途经点满足椭球条件只是必要条件，最终仍需核对所有要求是否覆盖，以及整个访问顺序的总路程是否超预算。

## 执行顺序

1. 保留原始条件和起终点的安全距离限制。
2. 在服务器请求中收紧候选球；星系模式再与已有坐标范围相交。
3. 收到候选后，先按实际坐标检查距离和，再进行星环／天体／站点等详细核验；不合格候选不消耗命中数额度。
4. 最终仍执行原有条件与工具专属规则。

普通字段 `distance` 与服务器当前参考点绑定时，不替换参考点和距离上下限。已有更小的查询球不扩大。几何边界向外扩张浮点容差，避免丢失刚好在边界的候选。A=B、零绕路和空候选均有回归测试。恢复查询的身份也包含路线边界，不能拿另一套路线参数继续旧断点。

## 性能与覆盖边界

只有确实缩小了候选覆盖、减少分页／详细核验，才算真实收益；不能保证所有查询都有固定提速倍数。缩小半径可能改变上游候选排序，有限结果／页数下首批结果不必与旧版一致，因此仍保留候选集最优而非全银河最优的提示。

固定响应回归验证新旧完整可行结果相同，并检查新范围减少候选页数；另有随机几何覆盖、边界、原距离字段语义和详细核验前淘汰测试。
