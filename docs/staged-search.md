# 分阶段核验与增量显示（开发版）

## 适用范围

主界面星系／站点搜索、殖民候选工具支持在整次搜索结束前显示已核实结果。
海盗任务、HGE、采购和多目标路线窗口未接入本次增量显示；路线方案仍需完成候选收集与整体求解后展示，不能把单个候选当成可行路线。

## 核验顺序

- 主界面保留现有普通条件／路线几何预筛，在本地派系数量核验通过之后才查询缺失站点。
- 站点数量条件通过后才查询站点条件组需要的完整站点记录。
- 站点条件组不符合或证据不足时，不再加载该星系的天体，也不查询最近有人距离。
- 天体／星环条件必须明确通过，才执行最近有人距离核验；未知不会作为命中。
- 殖民候选在补查缺失站点前，先本地核对最低估值和参考距离，并跳过已扫描身份。
- 原有同站匹配、数量分类、数据缺失和结果上限语义保持不变。未核实候选不消耗命中额度。

## 显示和线程

搜索引擎的可选 `on_results(batch)` 回调只发送新出现、完整通过本次查询条件的行。回调在搜索线程执行，收到的是独立深拷贝；调用者不得直接操作 Tk。

主界面通过线程安全待显示缓冲区合并结果，交给已有主线程派发器追加表格行，不为每条命中重建整个表格。殖民窗口使用已有事件队列追加结果。最终结果到达后仍统一校准表格。

正在显示的行是**已核实的部分结果**，不是已完成搜索或全库结果。进度条、停止、网络暂停和翻页限制仍使用原有状态。主界面中途切换语言会按当前已显示行重绘；最终 CSV 仍使用完整结果及原有证据列。

回调只发送新增行：继续查询不会重复发送已保留命中。网络中断或停止之前已显示的命中保留；新查询清空旧结果，旧任务的待显示回调不应污染新查询。

## 验证与限制

回归覆盖低成本拒绝时不调用昂贵接口、未知站点证据、天体核验前不发出命中、下一页请求前发出结果、回调快照隔离、停止／续查去重，以及 GUI 在工作线程尚未返回时已显示结果。

这项改动主要减少无用请求、缩短首条结果的等待时间，不保证固定提速倍数。分页与详细核验仍是有界批次，并没有新增无界后台请求或提前预取所有分页。
