# v0.1.4-r1 — Search refinements

## English

Windows x64 revision of v0.1.4. The original release remains available for rollback.

**Scope: uses the previously built EXE and its original corresponding source archive, without rebuilding. HGE and the later Copy engineer system button are NOT included; both remain development-source additions.**

This is a revision of 0.1.4's existing filtering, interaction and network handling. The original v0.1.4 release and assets remain unchanged.

- Unified ring selection with scope-aware evidence and preserved advanced groups; unknown data never proves absence.
- Shared star/planet conditions in the main and colonisation windows, including optional main-star status. Companion stars remain eligible unless explicitly restricted; legacy planet conditions retain their meaning.
- Same-station condition groups and separate non-carrier/orbital/planetary counts in system searches.
- Separate Fixed/Gimballed/Turreted specification choices in engineer shopping; the same stock item must satisfy name, specification and mount. Unknown or conflicting mount evidence fails the restriction. Choices persist across sessions and CSV includes mount evidence. Legacy plain specifications remain mount-unrestricted.
- Verified partial results retained after transient failures or manual stops; unchanged searches can continue. Changed-query confirmation can be cancelled without losing previous results.
- Short-lived body caching, shared evidence and bounded verification batches reduce duplicate or unnecessary requests.
- Overall candidate/match progress and measured approximate ETA intervals when sufficient samples exist, excluding paused time.
- Process-wide Spansh pacing: at most two requests in flight, at least 0.35 seconds between starts, shared cooldown, adaptive slowdown and at most two automatic retries respecting Retry-After. Suggestions share the governor; exhausted retries are not multiplied by full-outfitting retries.
- Consistent 0.1.4-r1 identity in the UI, CSV and Windows product version; numeric Windows version 0.1.4.1. Reorganised bilingual README.

Back up `%LOCALAPPDATA%\EliteDangerousFilter` and retain the previous EXE. Both versions share the data directory. Search checkpoints are in memory only and are lost on close/restart. Request control does not coordinate separate program instances or throttle unrelated providers. Active HTTP calls still use their existing timeout. The upstream cause of 502 errors is unproven; this revision does not guarantee their elimination. Records are neither live nor galaxy-complete. Current README screenshots remain labelled original-v0.1.4 offline demonstrations pending replacement.

Validation scope: the original source archive discovers 552 tests. In the build environment even a standalone Tk window cannot map to a visible input desktop; six visible-window/pixel/layout/popup tests produce 33 assertion failures. These checks are explicitly reported separately, not claimed as passed or hidden by changing assertions. The original packaged EXE was rechecked for offline startup, mount selection and separate-process sessions. README screenshots remain labelled original-v0.1.4 demonstrations, not final-build captures. Source assets correspond to the corrected release tag and exclude personal caches/sessions. Verify SHA256SUMS.txt; hashes are not code signatures.

The environment-aware run passed **546 tests with 6 explicitly skipped for the unavailable visible desktop**, and no other failures/errors. Skipped visual checks have not passed. The original EXE's offline startup, mount selection and independent-process session write/read checks all passed again. Product version 0.1.4-r1, numeric version 0.1.4.1. EXE and source ZIP hashes are unchanged from the previous build. See VALIDATION.json for the exact limitations.

## 中文

Windows x64 的 v0.1.4 修订版，保留原版以便回退，不替换原发行附件。

**发行范围：按用户要求直接使用上一次已打包的 EXE 与对应源码包，不重新构建。不包含 HGE，也不包含后来新增的“复制工程师星系名”按钮；这两项只保留在开发源码。**

此版沿用 0.1.4，作为现有筛选、交互及网络处理的修订；保留原 v0.1.4，不替换其发行附件。

### 调整内容

- **星环筛选整理**：统一“不限／有星环／指定类型／无星环”入口，保留高级星环组；站点按所属天体、星系按已收录天体核验。缺失资料不视为无星环。
- **天体条件整理**：主界面和殖民工具共用恒星／行星类别、恒星子类型及独立可选的“是否主星”。不指定主星时允许伴星；旧星球条件保持原有语义。
- **站点条件核验**：星系搜索支持同一站点内的组合条件及非航母／轨道／地表站分类数量，避免跨站拼接条件。
- **工程师采购支架选择**：型号按固定／万向／炮塔拆成独立选项，同一库存条目必须同时符合名称、型号与支架；未知或冲突证据不视为匹配。支架选择随会话保存，CSV 显示对应支架证据。旧清单纯型号仍不限制支架。
- **中断恢复**：主界面与殖民检索在暂时网络故障或手动停止后保留已核实结果，相同条件可继续；更改条件需确认重查，取消确认保留旧结果。
- **请求与速度**：短时复用天体资料，复用星环／天体证据，限制批次和邻近有人星系核验并发，减少重复或不必要请求。
- **进度显示**：显示整体候选、命中及当前步骤；有足够测量样本时提供大致剩余时间区间，暂停时间不计入速度估算。
- **网络稳定性**：同一进程内 Spansh 请求合计最多两个在途，请求开始至少间隔 0.35 秒；暂时错误共享冷却、逐步降速并最多自动重试两次，遵守 Retry-After。字段建议也走同一请求控制；满配件工具避免叠加耗尽后的重试。
- **版本识别与说明**：界面、CSV 和 Windows 产品版本统一标记 0.1.4-r1；Windows 数字版本为 0.1.4.1。整理中英文 README。

### 限制与升级

- 升级前备份 `%LOCALAPPDATA%\EliteDangerousFilter`，保留旧 EXE。修订版与原版共用数据目录；旧条件、草稿和 CSV 信息保持兼容。
- 继续检索的断点仅存在于内存；关闭程序或重新开始后不会保留。尚不支持跨启动恢复搜索。
- 请求控制只协调同一个程序进程，不协调多个 EXE 实例；其他数据提供商不受 Spansh 节流影响。
- 502 的上游根因尚未确定，此修订不保证消除 502。停止可中断冷却等待，但不能立即撤回已经发出的 HTTP 请求。
- 数据不是实时或全银河完整记录，缺失不证明不存在；库存、许可和殖民资格仍需游戏内核实。
- README 截图仍为明确标注的原 v0.1.4 离线演示，不包含此次全部界面变化；不将旧截图冒充最终 EXE 截图。
- EXE 未做代码签名；最终交付应包含对应源码和 SHA256SUMS.txt。哈希不是发布者数字签名。
