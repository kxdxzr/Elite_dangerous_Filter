# Elite_dangerous_Filter v0.1.4-beta.1 — UI Refactor / UI 重构测试版

## English

**Beta / pre-release: this release refactors the UI. Undiscovered bugs and regressions may remain; it is not guaranteed to be bug-free.** The latest stable release remains [v0.1.3](https://github.com/kxdxzr/Elite_dangerous_Filter/releases/tag/v0.1.3).

Download **EliteDangerousFilter.exe** for 64-bit Windows; no Python installation is required. Queries require internet access. The EXE is unsigned and may trigger Windows SmartScreen. Check it against **SHA256SUMS.txt** before running.

### Changes

- **Follow system / Light / Dark** appearance selector in the main-window header. Follow system is the default and tracks Windows' app colour preference while running; unsupported systems fall back to light. The selection is saved with the session.
- Shared colours across the main window, tool windows, tables, dropdowns, suggestions and text editors. Refreshed fonts, spacing, condition cards, primary search button and alternating result rows. Native file/OS dialogs keep the system appearance; title-bar colours depend on Windows support.
- Scrollable, resizable settings/results panes in the neutron planner, keeping results and the full-tank warning accessible. Copy/export footers are kept visible instead of being pushed below expanding tables.
- Existing search rules are unchanged. Result-header sorting, copy identity, localisation, CSV route order and unsortable ordered-waypoint editing are preserved.

### Before testing

- **Back up `%LOCALAPPDATA%\EliteDangerousFilter` first.** The Beta shares the stable version's session/cache/favourites directory; it is not automatically isolated. Keep the stable EXE available for rollback and restore your backup if necessary.
- This is a UI-focused Beta, not a promise of new search capabilities or live-data correctness. Pirate finding and neutron-assisted rare-goods ranking retain their existing testing/experimental limitations. Verify stock, access, discounts and actual routes in game.
- If you encounter a problem, report the version, Windows display scaling, language, selected appearance, reproduction steps and a screenshot. Remove private data before sharing session files or logs.

Offline UI screenshots and smoke/session write–restart–read checks of the actual packaged EXE are also part of release validation. **These checks cannot rule out all potential bugs**, especially live-network, display-scaling and system-theme edge cases.

### 更新内容

- 主窗口顶部新增 **跟随系统／浅色／深色**。默认跟随系统，运行中跟随 Windows 应用颜色设置；不支持的系统回退浅色，选择随会话保存。
- 主窗口、工具窗口、表格、下拉列表、联想列表与文本编辑区统一配色；调整字体、间距、条件卡片、主要搜索按钮和表格交替行底色。原生文件选择／系统对话框保留系统外观，标题栏颜色视 Windows 支持情况而定。
- 中子规划器设置区可滚动，并可拖动分隔条调整设置／结果区域；结果表及满油假设提醒保持可访问。复制／导出操作栏避免被扩展表格挤出窗口。
- 不改变既有检索规则；保留表头排序、正确复制、中英切换、CSV 实际航线顺序；有序途经点编辑列表仍不启用排序。
