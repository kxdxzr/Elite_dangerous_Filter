# Elite_dangerous_Filter v0.1.4-beta.2 — Planner Split & Search Updates / 规划器拆分与检索更新

## English

**Beta / pre-release: this continues the UI refactor and includes extraction and search changes. Undiscovered bugs and regressions may remain; it is not guaranteed to be bug-free.** [v0.1.3](https://github.com/kxdxzr/Elite_dangerous_Filter/releases/tag/v0.1.3) remains the latest stable release.

Download **EliteDangerousFilter.exe** for Windows x64; no Python installation or API key is required. Queries need internet access. The EXE is unsigned and may trigger SmartScreen. Verify **SHA256SUMS.txt** before running.

### Changes since beta.1

- **Neutron planner extracted** to [Elite_dangerous_Neutron_Planner](https://github.com/kxdxzr/Elite_dangerous_Neutron_Planner). This EXE no longer includes the planning UI or ship parser; its button opens the standalone repository. Old filter favourites are not deleted, and the standalone tool supports explicit import without changing the old file. Experimental rare-goods neutron geometry remains in the filter.
- **DPI and font fix:** declare Windows system-DPI awareness to avoid bitmap-scaled blurry text; prefer Microsoft YaHei UI / YaHei when installed. No bundled fonts and no unsupported PerMonitorV2 claim.
- **Engineer shopping:** Any / S / M / L ship-size landing-pad filter, confirmed-pad result/CSV column and saved choice. M accepts M/L; L requires L. Unknown pad evidence does not pass an enabled filter, and the same station must satisfy the shopping list and pad requirement.
- **Personal Power bonuses:** choose a pledged Power (default None), with an explicit maximum-rank assumption enabled by default. Eligible weapon bonuses are 30% for Arissa / Archer / Yuri Grom and 40% for Denton in their territory. Actual commander rank is not read. Uncheck for public-only discounts. No invented stacking or carrier bonuses.
- **Public discount caveats:** Archer's public discount is excluded due to reported non-application; its separate personal-rank bonus is not blanket-disabled. Mahon's ordinary Cargo Rack / HRP 20% discount requires Fortified / Stronghold; Guardian HRP / SRP broker discounts remain excluded. Li Yong-Rui's 15% public rule remains enabled in Fortified / Stronghold systems. UI and docs identify the reported bugs; this is not live checkout validation.
- **Pirate / RES expansion:** minimum mission factions **0** retains task results and adds Spansh RES-system candidates filtered by target controller / Power and target radius; **1–8** uses mission search only. No separate mode selector. Source-only filters are disabled but their drafts retained at 0. Known mission sources rank first; unlisted sources show **No data** in the existing column. Supplementary targets are deduplicated against mission results.
- Unknown EDTools targets are checked against Spansh body records even without a ring-distance maximum. Rings only infer RES, never Low / Regular / High / Haz; specific types require explicit records. Available body data with no rings excludes the target; failed/incomplete coverage does not prove absence. EDTools zero-ring values are a filtering policy, not independently verified in-game absence.
- Source controlling factions are annotated only for known task sources, grouped sources are labelled individually. Empty UI/CSV cells use a short **`-`**, while Unknown / No data retain their meanings. CNB fallback remains selectable at 0 and is decided only after combining the searches; incomplete/unknown coverage cannot prove no RES hits.
- Known-stage progress uses real counts/percentages; unknown totals show counts/status without a bouncing bar. Pirate/engineer settings scroll independently so results/actions stay visible at high scaling; the English Power selector shows None correctly. Bilingual documentation and illustrative screenshots are updated.

### Before upgrading

- **Back up `%LOCALAPPDATA%\EliteDangerousFilter` first.** Beta and stable share this session/cache directory. Keep the stable EXE and your backup available for rollback.
- **Saved minimum mission factions = 0 now enables expanded RES searches**, including in older sessions. Choose 1–8 for task-only searches. Mission rows use distance from the source to the reference; supplementary RES rows use the target's distance. These are not source-to-target distances.
- Spansh data and EDTools catalogues can be incomplete or stale. A ring is not a confirmed RES; no known record is not proof of absence. No live mission-board API or guaranteed stock/discount/route is provided.
- Report version, Windows scaling, language, appearance, relevant filters and reproduction steps; remove private data from screenshots/session files/logs.

### 相比 beta.1 的更新

- **中子规划器已拆分**至[独立项目](https://github.com/kxdxzr/Elite_dangerous_Neutron_Planner)。本 EXE 不再内置规划界面和配船解析，按钮仅打开新仓库。旧收藏不删除，独立版可手动复制导入，不修改原文件。稀有商品中子几何顺路筛选仍保留。
- **DPI／字体修复：**声明 Windows 系统 DPI 感知，避免缩放造成文字发虚，优先使用已安装的微软雅黑 UI／微软雅黑。不捆绑字体，不宣称已实现 PerMonitorV2。
- **工程师采购：**新增不限／S／M／L停机坪筛选及已确认停机坪结果／CSV列，选择随会话保存。M接受M／L，L仅接受L；未知坪数据不能满足启用的筛选，且须与采购清单由同一站满足。
- **个人 Power 优惠：**可选择效忠势力（默认无），默认勾选并明示“假设已解锁满级奖励”。适用武器为 Arissa／Archer／Yuri Grom最高30%、Denton最高40%，限对应领地，不读取真实等级。取消勾选则仅计算公共优惠，不猜叠加或航母优惠。
- **公共优惠例外：**Archer公共折扣因已报告的未兑现 Bug不计入，但不一并禁用独立个人等级优惠。Mahon普通货架／HRP的20%优惠仅限Fortified／Stronghold，Guardian HRP／SRP科技经纪人优惠因已报告Bug排除。LYR在Fortified／Stronghold的15%公共规则保留。界面及文档提示Bug，不代表实时核验结算价。
- **海盗／RES扩展：**最少任务派系数为 **0** 时保留任务结果，并用 Spansh 按目标控制小派系／Power、目标距离补充RES星系；**1–8**仅检索任务，不另加模式开关。0时来源专用条件停用但保留草稿；有已知来源的优先，未收录在原“任务来源”列显示“无数据”，新增目标不重复追加已有任务目标。
- EDTools地点未知的目标，即使距离留空也用Spansh天体数据复核。星环仅推定RES，不推定Low／普通／High／Haz，指定类型必须有明确记录；可用天体记录中无环则排除，失败／不完整不能证明不存在。EDTools零星环值是筛选策略，不等同于游戏内独立确认无环。
- 仅为已知任务来源补查来源控制派系，多来源分别标注；界面／CSV空值统一短横线 **`-`**，保留“未知／无数据”原义。0时仍可选择CNB回退，须在合并全部检索后才决定；未知／不完整不能作为无RES证据。
- 已知阶段显示真实数量／百分比，总数未知时显示数量和状态，不再来回晃动。海盗／工程师表单独立滚动，避免高缩放下结果和操作栏被挤出；修正英文Power选项的“无”翻译。同步双语文档与离线演示截图。

### 升级前注意

- **先备份 `%LOCALAPPDATA%\EliteDangerousFilter`。** Beta与稳定版共用会话／缓存目录；保留稳定版EXE及备份，必要时回退。
- **旧会话中最少任务派系数为0也会启用扩展检索。**仅要任务时请选择1–8。任务配对行的距离针对来源，补充RES行针对目标，均不是来源到目标距离。
- Spansh／EDTools可能缺失或陈旧；有环不等于已确认RES，未收录不等于不存在。程序没有实时任务板接口，不保证库存、折扣或实际航线。
