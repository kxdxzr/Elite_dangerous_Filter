# v0.1.4 — Fully outfitted stations & persistent stock snapshots / 满配件空间站与库存缓存

## 中文

**v0.1.4正式版，承接beta.1／beta.2的UI及检索改进。正式版不代表无Bug，也不保证第三方库存、折扣或地点始终准确。海盗任务候选功能仍处于测试中。**

### 下载与升级

- Windows x64：下载`EliteDangerousFilter.exe`，无需Python或API key。
- 先备份`%LOCALAPPDATA%\EliteDangerousFilter`。Beta与正式版共用数据目录，保留旧EXE和备份以便回退。
- EXE未签名，可能触发SmartScreen；运行前核对`SHA256SUMS.txt`。首次联网构建及手动更新需要网络。
- 数据目录中的缓存不随安装包分发；不包含下载的第三方全量装备／库存、用户会话或凭据。

### 相比beta.2新增

1. **查找满配件空间站**：按已知目录逐项核验同站普通／Power配件真实规格，不用尺寸／评级笛卡尔积猜库存，不拼接多站；排除航母及要塞航母。
2. **独立可选条件**：公共折扣、AX装备、通用多功能无人机控制器7A／7C、Merc特殊装备、三组舰船及对应船体装甲、Guardian科技经纪人。折扣默认不要求；要求时默认LYR，并可包含Jameson Memorial等其他已知公共规则来源。
3. **一次采集，多次筛选**：首次及手动更新固定以Sol为中心、20,000 ly采集最宽松站点名单，不受显示条数限制；后续改条件复用本地库存。
4. **换参考点无需重扫库存**：仅补查缺少的星系坐标，重算距离并排序；扩大半径只筛已有名单，不会自动发现名单外站点。远离Bubble后该名单可能不适用。
5. **缓存原位更新**：同一个缓存文件成功后原子覆盖，失败保留原数据。已有同范围完整缓存直接迁移复用；旧小范围缓存需手动更新。界面显示缓存距今整天数，并加粗提示首次扫描较慢。
6. **身份及资料复核**：优先用数字装备ID；仅符号不能区分普通／Merc时保持不确定。同市场EDSM仅补证可明确识别的库存，标注其未提供库存时间。最终命中补查Spansh许可、经纪人、距离等空字段。
7. **明确加价与覆盖范围**：i Sola Prospect／Brestla显示公共加价20%；Attilius Orbital的部分配件30%优惠不冒充全配件折扣。
8. **导出与维护**：CSV项目信息区下方记录查询条件快照，结果记录目录／规则版本、库存来源、快照时间及范围。提供完整API开发参考及可分享的公开数据源参考。
9. **装备清单独立更新入口**：手动从项目GitHub版本化清单Release下载JSON，校验格式、兼容性、身份与哈希，保留可回退版本；不执行下载代码。首份清单Release尚未发布，按钮会明确提示。SHA256不是数字签名。

### 其他调整

- 工程师采购表单／列表布局调整，采购列表内部滚动；选择有个人优惠的Power后统一明示满级假设，选择“无”仅公共优惠，不读取玩家等级。

### 必须了解的限制

- **首次扫描可能需要数分钟到十多分钟**，取决于网络、候选量和第二来源复核。后续本地筛选更快，但不承诺瞬时完成。
- “满配件”相对于此版本目录及勾选条件，不是官方对未来全部产品的保证。当前不要求`_free`机库、Mk II舰载机库、普通／Mk II大型行星车库；High-Yield Enzyme Missile Rack 2B也从Merc需求中明确排除，均有文档记录。
- **Merc严格条件仍可能零命中**：共享符号／缺少独立ID使24项规格在创世诊断中无法证实；不会为了有结果直接按名称放行。移除高收益酶导弹架不解决这些歧义。
- 站点“未收录”不等于游戏内确认缺货；快照不是实时库存。部分优惠是已知规则推算，不是实时结算验证。
- 只有完整采集才替换缓存；页数不足、深分页上限、网络失败或停止可能使更新失败，需要重试或增加页数预算。
- 更新装备清单不自动刷新库存；已有库存快照绑定原目录，需要手动更新数据后应用新清单。
- 任何半径的本地查询都只覆盖已保存名单，不能把“名单筛选完成”理解成新范围全银河遍历完成。

## English

**Stable v0.1.4 incorporates the beta.1/beta.2 UI and search improvements. Stable does not mean bug-free or guarantee third-party stock, discounts or coverage. Pirate mission finding remains experimental.**

### Install

Download the Windows x64 `EliteDangerousFilter.exe`; Python and API keys are not required.
Back up `%LOCALAPPDATA%\EliteDangerousFilter` first: Beta and stable share that directory.
Keep the previous EXE and backup for rollback. The EXE is unsigned; check `SHA256SUMS.txt`.
No personal sessions, credentials or downloaded full third-party stock/catalogue database are bundled.

### New since beta.2

- **Find fully outfitted stations:** actual same-station ordinary/Power variants, excluding carriers and Stronghold Carriers. No inferred size/rating combinations or cross-station stock merging.
- Optional public discounts, AX equipment, 7A/7C Universal controllers, Merc equipment, ship groups with hull armour, and Guardian broker. Public discounts are off by default; when enabled, LYR is the default scope with other public-discount stations optionally included.
- **Persistent widest-scope snapshot:** initial/manual discovery is fixed at Sol + 20,000 ly, independently of display limits and query options. Subsequent stock checks filter that shortlist locally.
- Changing reference only retrieves missing system coordinates, recalculates and sorts distances. Increasing radius does not discover stations outside the shortlist. This is primarily useful around the Bubble.
- Successful manual updates atomically replace the same cache; failures retain the previous data. Compatible fixed-scope caches migrate without redating stock. The UI shows cache age and prominently warns that the first scan is slow.
- Numeric-ID identity and strictly same-market EDSM cross-checking; ambiguous Merc stock remains unconfirmed. Final-hit metadata is completed from Spansh without guessing missing fields or redating old stock.
- Explicit **20% markup** at i Sola Prospect, Brestla; Attilius Orbital's partial 30% discount is not treated as an all-module benefit.
- CSV preambles include saved search conditions; results retain catalogue/rule versions, evidence sources, and snapshot time/scope.
- Manual data-only GitHub catalogue updates with compatibility/identity/hash validation and rollback. No catalogue release has been published yet. Hash checking is not publisher-signature verification; downloaded code is never executed.
- Engineer shopping layout and maximum-rank Power assumptions, wider rare-goods selectors, maximum-only carrier count, and removal of the standalone-planner button. The neutron planner remains a separate project linked in the README.

### Limitations

The first scan may take minutes to more than ten minutes; network and identity checks vary.
Later local searches are faster, not guaranteed instantaneous. Stock is not live.
Completeness is relative to the known catalogue and selected options. Claimable `_free` hangars,
Mk II Vessel Hangars, both Large Planetary Vehicle Hangar families and the Merc High-Yield
Enzyme Missile Rack 2B are explicitly outside current requirements, with review notes retained.

Strict Merc searches may still return no hits: 24 variants could not be independently identified
in the Jameson diagnostic. Removing the enzyme rack does not resolve those ambiguities.
No known record is not proof of absence. Prices/discounts and eligibility require in-game verification.
Incomplete downloads never replace the valid cache. Catalogue updates apply when stock data is
manually refreshed; existing snapshots retain their catalogue version.

Validation covers automated tests, the actual EXE's offline smoke and independent-process session
checks, and live snapshot/distance regression checks. These do not guarantee every live scenario.
The corresponding `EliteDangerousFilter-0.1.4-source.zip` includes source, tests and build instructions.
