- Tighter safe route envelopes for shopping and waypoints, with unchanged final checks. Cheap checks precede expensive station/body/neighbour verification.

- HGE candidate filtering with optional same-system Manufactured trader evidence; not live signals or guaranteed drops. Engineer system copying and compact mount-aware purchase specifications.

Back up the shared data directory and retain your old EXE. This is an unsigned prerelease and does not replace v0.1.4-r1 as Latest. See `VALIDATION.json` for exact checks and remaining limitations. Real packaged-to-packaged self-update dialogs and SmartScreen behavior have not been manually accepted. ## 中文

**Windows x64 测试版。** 不替换最新正式版 v0.1.4-r1，不修改旧标签及构建附件。建议保留旧 EXE，并先备份 `%LOCALAPPDATA%\EliteDangerousFilter`；两版共用该目录。

### 新增与改进

- **多目标途经规划**：从主界面捕获最多六组独立要求，指定起终点与绕路上限，优先减少停靠次数，再缩短几何路程。同一站点可满足多组要求；不同站点分别计次。提供条件组保存和核验证据。仅在有限查询候选内优化，不是跃迁导航，也不保证燃料、许可或全银河最优。
- **EDTools 完整本地清单**：随程序附带 28,722 条任务配对和 550 个地点记录，首次使用不必下载清单。所有半径均从本地全量 JSON 生成候选；用户更新版优先。进入海盗工具后台检查更新，通常最多每天一次，有变化需确认才安装；两份数据原子更新，失败保留旧版，运行中查询固定同一代数据。动态 BGS／站点资料仍独立联网刷新。
- **路线范围收紧**：采购和途经规划采用安全椭球包围范围，并提前淘汰几何超预算候选；保留最终跳数、绕路和原条件校验。有限分页时首批候选可能变化，不承诺固定提速倍数。
- **昂贵核验后置**：先检查普通条件、派系数量、站点条件和天体条件，再查询必要的详细资料及最近有人距离。殖民候选先排除距离／估值不合格项，再补查站点；未知证据不作匹配。
- **边查边显示**：主界面和殖民候选工具增量显示完整核实的行，停止保留已核实结果，继续检索不重复追加。海盗和路线窗口尚未接入增量显示，路线必须完成整体求解才展示。
- **HGE 可能星系查找器**：按材料、控制派系效忠／当前状态、人口及记录时间筛选可能星系，可选核对同星系 Manufactured 材料商。它不是实时信号查询，不保证 HGE 存在、剩余寿命或材料掉落。
- **采购交互**：独立武器支架核对和紧凑型号显示，新增复制工程师所在星系；保留同站库存、规格和支架身份检查。
- **确认式 EXE 更新**：后台检测最新正式版，确认后下载并核对 SHA256；再次确认并保存设置后才退出替换、备份旧 EXE 和重启。不自动订阅 beta，不自动降级到旧正式版。更新助手的启动调用失败可回滚，但不能检测新程序启动后的崩溃。
